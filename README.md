# Ciencias Sociales III — Unidad I · Monografía digital multimedia (v2.0)

**Tema:** El Estado de bienestar y la transformación social. Primera progresión de Ciencias Sociales III. Material de bachillerato, con ejemplos contextualizados en Guerrero.

## Contenido
- `index.html`: monografía, navegación, 12 capítulos, galería, infografías, fichas, audiovisuales y autoevaluación.
- `assets/`: seis ilustraciones e infografías SVG originales para uso en clase.
- `recursos.json`: catálogo editable de enlaces a videos, audios e infografías.
- `PROMPTS_NOTEBOOKLM.md`: nueve instrucciones para generar videos, audios, infografía, fichas y presentación en NotebookLM.
- `Apuntes_Unidad_I_Ciencias_Sociales_III.docx`: apuntes académicos editables.

## Publicación en GitHub Pages
Subir el contenido íntegro de esta carpeta a `unidad_I/` o a la raíz de un repositorio. Activar Pages sobre la rama y directorio correspondientes. Ingresar a `/unidad_I/` para abrir la monografía. Mantener juntas las rutas de `assets` y `recursos.json`.

## Integrar recursos
Editar únicamente las URL del catálogo `recursos.json`. Las entradas vacías se visualizan como recursos pendientes; **no se inventan contenidos**. Se admiten URLs https de YouTube, MP3, MP4 y otros enlaces externos. Para materiales compartidos de NotebookLM, si el servicio no permite reproducción incrustada, se abre la página del recurso.

## Recomendaciones docentes
Verificar cada video y audio antes de publicarlo. Diferenciar datos documentados de supuestos del caso hipotético de Guerrero. Evidencia sugerida: actividades en cuaderno y reflexión final, sin puntuación adicional por audiovisual salvo disposición docente. El cuestionario es formativo; no almacena calificaciones oficiales.
