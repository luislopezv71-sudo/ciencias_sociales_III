# Ciencias Sociales III — Monografía multimedia v3.0

Unidad I: Estado de bienestar. Estructura por capítulos integrados: explicación extensa, gráfico pertinente, video/audio si aplica y actividades en cuaderno.

## Publicación
Subir `index.html`, `recursos.json` y la carpeta `assets/` juntos a GitHub Pages. No mover las imágenes fuera de `assets/`.

## Vinculación de NotebookLM
Editar las claves `url` de los siete recursos en `recursos.json` y publicar el archivo. Los videos de YouTube pueden integrarse, mientras que enlaces de NotebookLM y Drive sin reproducción directa aparecen como enlaces externos. Los audios MP3/M4A públicos se reproducen mediante HTML5.

## Evaluación
La retroalimentación es local y no constituye un registro de calificaciones. Las actividades se resuelven en el cuaderno; el docente puede adaptar la rúbrica.

## Producción
Ver `PROMPTS_NOTEBOOKLM.md` para la generación de contenidos audiovisuales.
